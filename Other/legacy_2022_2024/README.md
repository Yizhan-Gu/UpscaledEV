# Legacy Reference Code

This folder preserves historical Anne/Isabel implementations. These files are
not part of the current 2025 EV+BESS study and must not be used as a
reproduction entry point.

## Anne_Isabel

Contains the older baseline/implementation scripts and Isabel_README.docx.
They target prior 2022/2024 DR/ELRP workflows, earlier LMP folder formats, and
machine-specific paths. They are retained only for formulation and project
history.

## Current Entry Points

upscaledev_imp.ipynb, upscaledev_imp_rollingMPC.ipynb, and
